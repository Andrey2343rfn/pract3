# 📱 Developer Card App

Практична робота: мобільний та десктопний додаток-візитівка розробника, створений за допомогою фреймворку **Flutter**. Проєкт містить інформацію про розробника, його навички, контакти та інтерактивні елементи інтерфейсу.

---

## 🛠 Що зроблено

1. **Налаштування середовища розробки (macOS):**
   - Встановлено та налаштовано Flutter SDK, Android SDK, необхідні інструменти командного рядка та конфігурацію Xcode.
   - Добився повної стабільності середовища за допомогою `flutter doctor` (відсутність помилок у конфігурації Flutter, Android toolchain та Xcode).
2. **Розробка інтерфейсу додатка (`developer_card_app`):**
   - Створено структуру проєкту згідно з архітектурними стандартами Flutter.
   - Реалізовано екран профілю розробника (`DeveloperProfileScreen`) з використанням карток (`Card`), списків та стилізованих віджетів.
   - Додано інтерактивні елементи (перемикання теми оформлення, інформаційні блоки з контактами).
3. **Тестування та деплой:**
   - Успішно запущено додаток на десктопному симуляторі macOS та перевірено його працездатність.
   - Створено віддалений репозиторій на GitHub та успішно завантажено вихідний код проєкту за допомогою системи контролю версій Git.

---

## 🚀 Як запустити проєкт

Для завантаження та локального запуску проєкту виконайте наступні кроки у терміналі:

1. **Клонуйте репозиторій:**
   ```bash
   git clone [https://github.com/Andrey2343rfn/pract3.git](https://github.com/Andrey2343rfn/pract3.git)
   cd pract3

```

2. **Встановіть залежності:**
```bash
flutter pub get

```


3. **Запустіть додаток** (на десктопі macOS або підключеному симуляторі):
```bash
flutter run

```
